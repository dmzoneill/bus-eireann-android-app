# Bus Eireann Android App

An unofficial Bus Éireann journey planner for Android.

## What it does

- Lets you choose where you are travelling from and to, with a date and
  time picker.
- Looks up matching connections and lists them as search results.

## Tech

- Java for Android

## Building

This is an Eclipse Android project (`AndroidManifest.xml`,
`default.properties` and `proguard.cfg`). Import it into Eclipse with
the Android Developer Tools, or build it with the Android SDK.
